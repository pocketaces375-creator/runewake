# RUNEWAKE: The Buried Age

An AI-backed fantasy trading card game with a node-based world map, an old-League-style rune system, and an archaeology progression layer.

**Genre:** Single-player-first digital TCG
**Platforms:** iOS + Android (offline-first)
**Stack:** C# .NET 8 engine + Godot 4.3 client + Python AI pipeline

See `docs/` for the full design specification.
